# MegaFaucet TikTok media automation

Dedicated **public** repository for media production and delivery to TikTok `@caesar_2111`.

## Status
- GitHub Actions can build a test vertical video with narration and commit it under `media/`.
- The first render is a **pipeline test**, not an approved promotional video and **must not be posted** to TikTok.
- Scheduling in Metricool is separate from GitHub Actions. Do **not** assume automatic TikTok posting works until tested end to end.
- No credentials or private project data belong in this public repository.

Once the workflow and generator have been installed, push events to the workflow/generator or manual workflow dispatch will render a demo MP4.
